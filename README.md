### What I work on

- **Anomaly detection and forecasting**: demand forecasts at customer–SKU–day level to flag abnormal purchase orders, with retraining, champion–challenger evaluation and CI/CD.
- **Multimodal search**: image and text embeddings (SigLIP, Jina) in PostgreSQL with HNSW, served as an API on Kubernetes.
- **Agentic systems**: multi-agent workflows with CrewAI, tool use and structured output.
- **Data platforms**: ETL on Azure Data Factory, Databricks and Cosmos DB.
